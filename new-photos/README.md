# Drop new photos here

Upload photos to this folder with whatever filenames they already have —
straight off the phone, drone or camera. Nothing needs renaming first.

Claude will then rename them, compress them to web size, write the alt
text, place them on the right pages, and delete this folder once the
photos have been moved into place.

Full resolution is fine and preferred. Do not shrink them beforehand —
resizing is done here so the originals stay sharp.
